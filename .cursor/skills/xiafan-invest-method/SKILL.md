# 夏凡投资方法论（可调用框架）

蒸馏自公开群聊与配图观点，**不是投资建议、不是实盘指令**。调用时：按清单走一遍，把结论写成「观察 / 假设 / 待验证」，并标日期；若与其后续纠偏冲突，以较新表述并列，勿只留一侧。

## 何时用
- 用户要按「夏凡思路」复盘大盘、主线、仓位或一篇市场叙事
- 要区分：趋势 vs 超跌反弹、左侧出清 vs 右侧补涨、危机剧本 vs 战术止盈
- 要检查：仓位是否绑架立场、是否跟大多数站一边

## 核心哲学（先对齐）
1. **资金为根**：基本面 / 技术面 / 消息面最终落到资金能不能进、愿不愿进。
2. **二级是血包**：市场为实体与主力服务；「救市」叙事要听做不听话。
3. **立场决定仓位**（理性）；反向则是情绪选手（仓位绑架立场）。
4. **结构性牛**：全面牛罕见；主线抱团 + 次线补涨更常见。
5. **熊市只有超跌反弹，牛市才有趋势**。
6. **人性不变**：同样剧本反复上演；与大多数一致时先自检。

## 调用步骤（按序）

### 1. 定层：周期 / 趋势 / 流动性
- 当前问题属于哪一层？不要用日线噪音回答周月问题。
- 口诀：**日线级别以下没有神**；周/月结构无恙，才谈加仓级机会。
- 策略版本自检：1.0 周期保本 → 2.0 趋势 → 3.0 流动性；你在用哪一版？

### 2. 看资金言行（听做不听话）
- 谁在买/卖：主线抱团资金、次线、国家队/汇金类 ETF、游资？
- 买入托底 vs 拉高出货：必须**分篇、分日期**，禁止用一个落款糊买卖两段。
- 利好满天飞 + 指数箱体横盘：优先怀疑「出货掩护」。

### 3. 定主线状态：趋势 / 箱体出货 / 资金归位
- **双头模型**：左头=主线顶（宜左侧出清）；右头=补涨顶（可偏右侧）。
- **资金归位**：主线出货后资金回到原产业（如资源/能源），多为**超跌反弹、无增量、短命**，勿当新牛趋势。
- **抱团集中度**（成交额头部占比一类指标）：历史末波常逼近高阈值（蒸馏样本里约 **55%**）；逼近后预期周线级调整 → 补涨 → 牛尾。数字用当时数据，勿死背旧值。

### 4. 定义机会：超跌 = 周线背离
- 熊市：一年大约有限次数的主线超跌；**只做主线超跌**，做完就跑。
- 牛市：进攻成长；熊市：防守价值 / 现金债券归宿（「熊市五点」：无为、等待、超跌就跑、货币债券等——按语境列全）。
- 支撑久守必陷、压力久攻必破；号位/颈线作假设，用周线验证。

### 5. 外部锚（可选）
- **十年期美债收益率**作全球资产锚之一；黄金更看 **实际利率**（名义−通胀预期），勿只盯名义利率。
- 地缘/大宗：区分 **长期危机剧本** 与 **战术止盈点位**；若前后改口，按日期并列，禁止合成单一点位真理。
- 指数点位：可用「容量比/总市值」破除「点位迷信」，但结论要可算、可引用。

### 6. 仓位与纪律
- 先问：仓位是否已决定你的立场？
- 止盈后 **管住手**；高低切 ≠ 大小换乱做。
- 融资当安全垫，勿轻易当进攻杠杆。
- 输出观点时声明：**观点 ≠ 指令**；无执业资质则不做一对一操作指导。

### 7. 人格化资金结构（辅助叙事）
- A=主线/国家队抱团；B=次线（资源、周期等）；C=深套旁观板块。
- 末段：A 拉升吸 B → 抱团冲顶；尾声 B 归位反弹、A 继续出货。
- 下一轮主线可能换人：用「谁会成为新的 C→A」提问，勿固定死板块名。

### 8. 交付格式（给用户）
用短结构回复：
1. **所处阶段**（牛末/过渡/熊初/超跌窗口/…）
2. **资金证据**（谁在动、听做不听话）
3. **级别结论**（周月 vs 日线）
4. **机会类型**（趋势 / 超跌反弹 / 不参与）
5. **风险与纠偏**（已知改口、双轨叙事）
6. **检查清单勾选**（见下）

## 一页检查清单
- [ ] 已分清周期 / 趋势 / 流动性层
- [ ] 已看资金与流动性的「做」而非只听「说」
- [ ] 已判断主线：趋势 / 出货 / 归位反弹
- [ ] 机会是否满足「周线背离级超跌」或明确趋势条件
- [ ] 已考虑美债/实际利率等外部锚（若相关）
- [ ] 已切换正确的牛/熊人格与风控
- [ ] 仓位未绑架观点；少数派自检做过
- [ ] 企业基本面与股价定价已两分（若谈个股）
- [ ] 输出含免责：观点≠指令

## 归因与禁用
- 缠论「摔杯」、结构位置论等：标为**引用他人体系**，非本框架原创。
- 新闻快讯数字：标来源，不写成框架内生结论。
- 禁止把某一历史八步时间表（含具体年月点位）当成永恒日历；若引用，必须写「某年某月样本剧本」并提示可能已纠偏。
